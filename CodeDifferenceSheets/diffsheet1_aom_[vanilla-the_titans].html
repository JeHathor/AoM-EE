Comparison notes

  • The 7 new function names are aiBreakpointSet, aiBreakpointGo, aiPlanGetUnitByIndex, aiTaskUnitTransform, kbUnitCostPerResource, kbGetPlayerHandicap and kbSetPlayerHandicap.
  • Four existing function names have replaced signatures: aiPlanCreate, aiPlanDestroy, aiPlanGetIDByIndex and xsVectorSet.
  • The The Titans file contains a concatenated line around kbGetResourceIncome and kbProtoUnitAvailable. The latter is present in both references and is not treated as a new or removed function.
  • Constants whose names already exist in Vanilla are excluded even where their values differ between the reference files; those differences can reflect version-specific sample/runtime context rather than newly introduced constants.
  • The XS files declare constants using const; they do not use a separate static declaration keyword.
